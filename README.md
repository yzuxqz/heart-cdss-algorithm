# Heart CDSS — Ensemble Learning for Early Heart Disease Detection

**Key features:**
- Evaluates 5 ML algorithms across 3 multi-scale clinical datasets (N=303 to N=70,000)
- SHAP-based model interpretability (global + local)
- Streamlit web prototype for single-patient prediction and batch screening

## Machine Learning Algorithms

| Algorithm | Type | Class Imbalance Handling |
|---|---|---|
| **Logistic Regression** | Baseline (linear) | `class_weight="balanced"` |
| **Random Forest** | Bagging ensemble | `class_weight="balanced_subsample"` |
| **XGBoost** | Boosting ensemble | `scale_pos_weight` (tuned via search) |
| **LightGBM** | Boosting ensemble | `is_unbalance=True` |
| **CatBoost** | Boosting ensemble | `auto_class_weights="Balanced"` |

**Hyperparameter tuning:** `RandomizedSearchCV` with `n_iter=25`, 5-fold stratified cross-validation, optimized for ROC-AUC (`roc_auc`). Train/test split: 80/20, stratified, `random_state=42`.

## Datasets

| Dataset | Records | Features | Positive Class |
|---|---|---|---|
| **UCI Cleveland** | ~303 | 13 clinical attributes | ~46% |
| **Framingham** | ~4,240 | 15 clinical attributes | ~15% |
| **Kaggle Cardio70k** | ~68,635 (after filtering) | 11 features | ~50% |

## Getting Started

### Prerequisites

- Python 3.10+ (tested with 3.13)
- Windows / Linux / macOS

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

For LightGBM and CatBoost (optional — used in experiments only):

```bash
pip install lightgbm catboost
```

### 2. Preprocess datasets

```bash
python run_preprocessing.py
```

Outputs go to `processed_datasets/`.

### 3. Run experiments (all datasets, all models)

```bash
# All-in-one (Windows)
run_all_experiments.bat

# Or manually per dataset
python run_experiments.py --dataset uci_cleveland --csv datasets/heart_disease_uci.csv --target num
python run_experiments.py --dataset framingham    --csv datasets/framingham.csv --target TenYearCHD
python run_experiments.py --dataset cardio70k     --csv datasets/cardio_train.csv --target cardio
```

**Key CLI flags:**

| Flag | Default | Description |
|---|---|---|
| `--test-size` | 0.2 | Test set ratio |
| `--seed` | 42 | Random seed for reproducibility |
| `--n-iter` | 25 | RandomizedSearchCV iterations |
| `--cv-folds` | 5 | Cross-validation folds |
| `--models` | all 5 | Comma-separated subset: `logreg,rf,xgb,lgbm,cat` |
| `--shap` | off | Generate per-model SHAP plots (experiment-level, not thesis-quality) |

Results are saved to `results/<dataset>/` with a timestamped `run_id`.

### 4. Build deployment artifacts

```bash
python build_system_artifacts.py
```

This picks the best model from each dataset's results, re-fits on the full dataset, and saves `model.joblib` + `schema.json` + `meta.json` to `artifacts/<dataset>/`.

### 5. Launch the Streamlit app

```bash
# Windows
start_system.bat

# Or directly
streamlit run app.py
```

The app provides:
- **Predict tab:** Single patient risk prediction with SHAP waterfall explanation
- **Explainability tab:** Global SHAP beeswarm and bar plots
- **Batch Predict tab:** Upload CSV for batch scoring (up to 5,000 rows)

## Evaluation Metrics

All models are evaluated on:

| Metric | Description |
|---|---|
| **Accuracy** | Overall correct predictions |
| **Precision** | Positive predictive value |
| **Recall** | True positive rate (sensitivity) |
| **F1-Score** | Harmonic mean of Precision and Recall |
| **ROC-AUC** | Area under the ROC curve (primary CV optimization target) |

Classification thresholds are optimized per model using **Youden's J statistic** on the training set.

---

## Key Findings

- **XGBoost** achieved the best overall performance on the large-scale Cardio70k dataset (Test ROC-AUC: 0.810, F1: 0.728)
- **CatBoost** showed the strongest recall on the imbalanced Framingham dataset (Recall: 0.597)
- SHAP visualizations revealed that **systolic blood pressure, age, and cholesterol** are consistently the most influential predictors across all datasets
